The export keeps your column order and the totals — all of them — match the source sheet. Open the file, check the rows, and send it on to finance by Friday. If a row looks wrong, the log shows which import step touched it, so you fix the source instead of the copy. Most teams finish in ten minutes, and support can run the import for you when the file is larger than fifty megabytes. Dates must use the year-month-day order, and merged cells should be unmerged first because the importer reads one value per cell. Anything it skips is listed in the log with the row number, so nothing disappears without a trace.
